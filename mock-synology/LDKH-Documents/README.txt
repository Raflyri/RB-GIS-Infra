Direktori ini mensimulasikan mount point NFS Synology DS218j (/mnt/synology/LDKH-Documents) pada lingkungan local development.
Simpan sampel file PDF legal (misalnya: SHM, AJB, Girik hasil scan OCR) di dalam folder ini untuk menguji secure file serving via Nginx X-Accel-Redirect dan FastAPI.
Pada lingkungan produksi Proxmox LXC, direktori /mnt/synology/LDKH-Documents akan di-mount secara read-only dari Synology DS218j.
